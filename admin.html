Admin sign-in

Paste the GREYBOX_ADMIN_TOKEN server secret to manage Greybox-owned data. It stays in this page's memory only — reload or Disconnect forgets it. Nothing is stored in your browser.

No token configured on the server? Ask the site operator to set the GREYBOX_ADMIN_TOKEN Pages secret (see README §5). Until then every request fails closed with 401.
