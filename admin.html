Roadmap

Heroes, Blocked Titles, Navigation, Footer, SEO, Integrations and Diagnostics are scaffolded in the sidebar as Soon — they become real editors in later increments. No placeholder controls were added.

Home Sections

Shelves on the homepage, in display order. Editing never destroys list context — it opens an editor drawer.

Collections

Rule-based rows behind /collection/:slug. Use the editor drawer to create or edit — no scrolling past the list.

Metadata Overrides

Explicit per-title fixes. Anything absent falls back to live TMDB data.

Greybox Picks

Titles marked ★ Greybox Pick via the existing overrides (featured + custom_badge). No new database — toggling here calls the same overrides API.

TMDB Search

Operator helper over the existing public /api/tmdb proxy. Actions reuse collections + overrides only.

General Settings

Homepage hero behavior. The full Heroes studio arrives later — this preserves the existing hero controls exactly.
