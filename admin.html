Home Sections

Collections

Manage the content, presentation and behavior of Greybox collections. Rule-based rows behind /collection/:slug — content lives here, hero presentation lives in Heroes.

Tags

Manage your editorial tags and the titles assigned to them. Tags are reusable content groups — use one as a Custom Tag source in any Home section or Collection. Identity is always media:TMDB ID, never title text.

Overrides

Control metadata, artwork and editorial presentation for individual titles. Anything absent falls back to live TMDB data — identity is always media:TMDB ID.

Heroes

Control how Greybox presents featured content and trailers — Home hero plus per-collection heroes.

Home Hero

Collection Heroes

Collections use default hero behavior (first title) unless a custom hero is configured. Custom heroes never change the collection's titles — only its hero.

Greybox Picks

Titles marked ★ Greybox Pick via the existing overrides (featured + custom_badge). No new database — toggling here calls the same overrides API.

TMDB Search

Operator helper over the existing public /api/tmdb proxy. Actions reuse collections + overrides only.

General Settings

Homepage hero behavior (same row the Heroes studio edits). Artwork/trailer are managed in Heroes — saving here carries the current server values through.
